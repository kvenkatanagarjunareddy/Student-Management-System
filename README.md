# 🎓 Student Management System

A **console-based Student Management System** developed using **Core Java**, **Object-Oriented Programming (OOP)** principles, and the **Collections Framework**.

The application provides complete student record management through **CRUD operations**, including adding, viewing, updating, deleting, and searching student records. It also uses **file handling for persistent data storage**, exception handling for reliable execution, and includes **average marks calculation** functionality.

## 🚀 Features

* ➕ Add new student records
* 📋 View all student records
* ✏️ Update existing student information
* 🗑️ Delete student records
* 🔍 Search students
* 💾 Store student data using file handling
* ⚠️ Handle invalid inputs and runtime errors using exception handling
* 📊 Calculate average marks
* 🧩 Uses Object-Oriented Programming principles
* 📦 Uses Java Collections Framework for managing student records

## 📂 Project Structure

```text
Student-Management-System/
│
├── Main.java
├── Student.java
├── StudentManager.java
└── README.md
```

### 📄 Main.java

The main entry point of the application.

It provides the console-based menu and allows users to select different student management operations.

### 📄 Student.java

Represents the **Student entity**.

It contains the student-related attributes and methods required to store and manage individual student information.

### 📄 StudentManager.java

Responsible for managing student records and implementing the major operations such as:

* Add student
* View students
* Update student
* Delete student
* Search student
* File-based data management
* Average marks calculation

## ▶️ How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/kvenkatanagarjunareddy/Student-Management-System.git
```

### 2. Open the Project

Open the project in any Java-supported IDE such as:

* IntelliJ IDEA
* Eclipse
* VS Code
* NetBeans

### 3. Compile the Java Files

```bash
javac Main.java Student.java StudentManager.java
```

### 4. Run the Application

```bash
java Main
```
